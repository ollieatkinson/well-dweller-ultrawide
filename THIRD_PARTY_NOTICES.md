# Third-party software

Release ZIPs include these components, packaged without further modification. Versions, download URLs, and SHA-256 hashes are declared in `CMakeLists.txt`.

- **SUWSF 2.3.0-guard.3** — [fork source](https://github.com/ollieatkinson/SUWSF/tree/v2.3.0-guard.3), based on [SUWSF by PhantomGamers](https://github.com/PhantomGamers/SUWSF), [MIT license](licenses/SUWSF-MIT.txt). Adds compatibility checks, atomic patch validation, synchronous ASI initialization, and compatibility warnings. Runtime file: `SUWSF.asi`.
- **Ultimate ASI Loader 9.7.4** by ThirteenAG — [source](https://github.com/ThirteenAG/Ultimate-ASI-Loader), [MIT license](licenses/Ultimate-ASI-Loader-MIT.txt). Its x64 `dinput8.dll` is renamed to `version.dll`.

No game files are distributed.
