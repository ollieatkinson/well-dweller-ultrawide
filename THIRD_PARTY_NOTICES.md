# Third-party software

Release ZIPs include these unmodified upstream components. Versions, download URLs, and SHA-256 hashes are declared in `CMakeLists.txt`.

- **SUWSF 2.3.0** by PhantomGamers — [source](https://github.com/PhantomGamers/SUWSF), [MIT license](licenses/SUWSF-MIT.txt). Runtime file: `SUWSF.asi`.
- **Ultimate ASI Loader 9.7.4** by ThirteenAG — [source](https://github.com/ThirteenAG/Ultimate-ASI-Loader), [MIT license](licenses/Ultimate-ASI-Loader-MIT.txt). Its x64 `dinput8.dll` is renamed to `version.dll`.

No game files are distributed.
